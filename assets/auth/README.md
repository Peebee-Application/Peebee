# Account illustration

`peebee-welcome.webp` is the shared account background for all seven Peebee application frontends. It is exported unchanged visually as a 1536 × 1024 WebP (quality 88), with a CSS mask providing the requested downward fade. The generated original is retained in the Codex generated-images folder.

Generated with the built-in image generation tool. Prompt:

> Use case: illustration-story. Asset type: background illustration for Peebee Uganda delivery app login and registration. Create one polished playful editorial 3D clay illustration, wide 3:2 composition. A friendly Ugandan delivery rider on a small scooter with a parcel, beside a market storefront and a few neat grocery bags, simplified warm shapes and rounded friendly style. Peebee palette only: warm off-white cream, charcoal ink/navy, mustard golden yellow, soft taupe neutral shadows. No green, blue, red or purple. Composition: all objects in upper two thirds, an airy cream backdrop and a generous clean lower third without objects so app content can sit below; subjects well separated, no cropped heads. Soft studio lighting, inviting and calm, suitable for a mobile welcome screen, crisp and high quality. No letters, logos, words, UI, borders, buttons, frames or watermark.

# Google button assets

Google's current gradient G was downloaded unchanged from https://developers.google.com/static/identity/images/g-logo.png. Google Sans Medium (Latin WOFF2) came from the Google Fonts stylesheet for `Google Sans:wght@500`; its SIL Open Font License is included as `GoogleSans-OFL.txt`.

The custom button uses Google's white/dark fill, border, text colour and Google Sans font from https://developers.google.com/identity/branding-guidelines. Its full width, 54px height and 17px corners match Peebee's Login/Register actions. Google's SDK remains the actual interactive control and retains the existing credential callback.
